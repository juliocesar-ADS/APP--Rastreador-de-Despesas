# Rastreador de Despesas

Aplicativo Android gratuito para registrar vendas e despesas, acompanhar o saldo do negócio, organizar gastos por categoria e consultar histórico e relatórios.

## Instalar no Android

Abra este link no Android para baixar a versão mais recente:

**[Baixar e instalar o Rastreador de Despesas](https://github.com/juliocesar-ADS/APP--Rastreador-de-Despesas/releases/latest/download/app-release.apk)**

Depois do download, abra `app-release.apk` e toque em **Instalar**. Por segurança, o Android pode pedir que você autorize instalações vindas do navegador ou gerenciador de arquivos. Essa autorização é controlada pelo Android e não pode ser removida por um link do GitHub. Não é necessário instalar Termux, criar conta, configurar servidor nem conectar à internet para usar o app.

## Como funciona

O aplicativo funciona offline em Android 7.0 ou superior. Vendas, despesas e categorias são salvas em um banco de dados privado no próprio aparelho. O app não solicita permissão de internet, não precisa criar conta e não envia informações para a nuvem.

**Importante:** os dados existem somente no aparelho em que foram cadastrados. Eles não são sincronizados nem copiados automaticamente. Desinstalar o app pode apagar os dados; exporte ou anote as informações importantes antes de removê-lo ou trocar de celular.
